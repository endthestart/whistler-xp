How it works

Whistler XP runs programs made for Windows using Wine. Wine is not an emulator: Windows programs run directly, and many work exactly as they do on Windows. The first time you run one, Whistler prepares a Windows environment — a folder that acts like a Windows C: drive with its own registry and settings.

Installing a program

1. Double-click the setup file (for example setup.exe or a .msi file) in Windows Explorer, or
2. Open Start → Wine Center and click Install a Windows program. The wizard asks for the setup file, where to install it, and which extra Microsoft components the program needs.

Installed programs appear in Start → All Programs in the same folders their setup program created, and in Wine Center.

Shared or separate environments

Most programs can share the default environment. Games and programs that need special components (such as an old .NET Framework or DirectX) work best in a separate environment, so changes made for them don't affect anything else. Create one from the install wizard or with Environment → New Environment in Wine Center.

Games

For Direct3D 9, 10 and 11 games, add the DXVK component in Wine Center. It translates graphics to Vulkan for much better speed on modern graphics cards.

If a program doesn't work

  • Install it again in a separate environment and select the components it lists in its requirements (Visual C++ runtime, .NET Framework, DirectX).
  • Try a different Windows version: Wine Center → Change environment settings → Pretend to be.
  • Some programs run better inside a virtual desktop window (same settings dialog, Display tab).
  • Look the program up in the Wine Application Database at appdb.winehq.org for tips from other users.
  • Click Stop all Windows programs in Wine Center if a program hangs.

Advanced tools

Wine Configuration (winecfg), the Registry Editor and Windows Task Manager are in All Programs → Wine and in each environment's Properties. Power users can use winetricks from Command Prompt.
