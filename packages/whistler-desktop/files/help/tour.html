Welcome

Whistler XP looks and works like the desktop you remember: the start button, the taskbar, My Computer, Control Panel and the Recycle Bin are all where you expect them. Underneath it is CachyOS, a fast and up-to-date Linux built on Arch, so it is quick, secure and modern.

The Start menu

Click start (or press the Windows key). Your most-used programs appear on the left; My Documents, My Computer, Control Panel and Run are on the right. Point to All Programs to see everything installed, including the Windows programs you add.

Files and folders

Your files live in My Documents, with My Pictures, My Music and My Videos inside it. My Computer shows your disks, CD drives and USB sticks, plus Windows Drive (C:) where Windows programs are installed. Deleted files go to the Recycle Bin until you empty it.

Internet and networking

Mozilla Firefox is your web browser. To connect to a wireless network, click the network icon in the notification area next to the clock.

Keyboard shortcuts

  • Windows or Ctrl+Esc — open the Start menu
  • Windows+E — My Computer
  • Windows+R — Run
  • Windows+D — show the desktop
  • Windows+L — lock the computer
  • Windows+Pause — System Properties
  • Alt+Tab — switch programs; Alt+F4 — close a window
  • Ctrl+Alt+Del — Task Manager

Adding Linux programs

Open Control Panel → Add or Remove Programs → Add New Programs and search the CachyOS and Arch Linux catalogs (thousands of free programs).

Keeping up to date

In Control Panel, click Software Update in the task pane, or run sudo pacman -Syu in Command Prompt.

Installing Whistler XP

When running from the CD or USB stick, double-click Install Whistler XP on the desktop. Setup erases the disk you choose and installs Whistler XP on it.
