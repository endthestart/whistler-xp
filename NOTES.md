# Working notes

## Decisions and assumptions

- **Base: CachyOS.** Packages come from the `[cachyos]` repository (generic x86-64, so the ISO
  boots on old hardware) plus Arch `core`/`extra`/`multilib`, which CachyOS itself layers on.
  Kernel `linux-cachyos`; `cachyos-settings`, `cachyos-hooks`, `chwd`, `cachyos-rate-mirrors`,
  `paru`, DXVK and VKD3D-Proton builds. The builder image is `cachyos/cachyos:latest`. Plain
  Arch packages are used only where CachyOS has no build of its own (Xfce, LightDM, Firefox, ...),
  as CachyOS does — and for Wine (below).
- **Wine: Arch's upstream `wine` (+ wine-mono, wine-gecko), not `wine-cachyos`.** wine-cachyos is
  Proton-based and its winemenubuilder does not write `.desktop` launchers, so installed Windows
  programs never reached the Start menu. Upstream Wine (newer, 11.x WoW64) does. Gamers can still
  install wine-cachyos or umu-launcher from Add or Remove Programs.
- **Name:** "Whistler XP" (XP's codename). No "Windows" in the distribution name.
- **Desktop:** Xfce 4.20 underneath (xfwm4, xfce4-panel, xfdesktop, Thunar) with Whistler's own
  pieces on top: start button plugin (C), start menu, welcome screen (LightDM greeter), dialogs,
  Control Panel, Wine Center, installer (Python/GTK 3).
- **Artwork policy:** the base system ships only original or openly licensed files.
  - Theme bitmaps, window frame, taskbar, cursors, logo (a pinwheel, not Microsoft's flag),
    wallpaper, account pictures and sounds are generated by `packages/whistler-artwork/gen/*.py`.
  - Icons: original SVGs in `packages/whistler-artwork/icons/src`.
  - The GTK stylesheet is B00merang's GPL-3 CSS; none of that repository's bitmaps are packaged.
  - Fonts: Wine's LGPL Tahoma lookalike, Fira Sans (OFL) standing in for Trebuchet MS,
    Liberation/DejaVu for the rest. No Microsoft fonts.
- **Optional originals add-on** (`whistler-xp-originals`): scripts only. At run time it reads the
  user's own XP CD/ISO or Windows folder and writes converted files to
  `/var/lib/whistler/originals`; `whistler-assets refresh` makes them win over the lookalikes.
  Removing the package deletes that folder and restores the lookalikes.
- **Swappable assets:** themes read `/usr/share/whistler/assets/current`, a symlink tree over
  `lookalike/` and the optional imported originals. Icons and pointers use theme inheritance
  (`Whistler` → `whistler-xp-originals` → `whistler-lookalike`).

## Testing done for iteration 1

- Live boot (UEFI and BIOS, QEMU with HVF on an Intel Mac): Plymouth splash → autologin → desktop in <1 min.
- Start menu, All Programs cascade, Run, Turn Off / Log Off (desaturating desktop), Welcome screen
  (password and wrong-password paths), My Computer, Control Panel, System Properties, User
  Accounts, Add or Remove Programs, Volume Control, Minesweeper, Alt+Tab, balloons.
- Wine: a MinGW-built test installer (`test/winapp/hello.c`) via double-click and via the Add
  Windows Program wizard → program in Start ▸ All Programs and on the desktop.
- Installer: full install to a blank disk (UEFI), reboot from disk, Welcome screen, log in.
- Originals add-on: offline install from `/opt/whistler/repo`, import from an XP CD image and
  from a CD-folder copy (169 theme images, 14 sounds, 45 fonts, 75 icons, 14 pointers, 58
  wallpapers, 23 account pictures, Welcome/Turn Off art), live switch, and fall-back.

## Known gaps / next ideas

- XP-style Explorer task pane inside Thunar itself (My Computer has it; regular folders use Thunar).
- Boot splash from the XP media (ntoskrnl bitmaps) in the originals add-on.
- Some third-party apps (pavucontrol, gnome-mines, Pinta) are GTK4/libadwaita and can't take the
  theme; Whistler ships XP-style replacements where it matters (Volume Control, Minesweeper).
- Alt+F4 on the empty desktop shows Xfce's logout confirmation, not the XP Turn Off dialog.
- Olive Green and Silver colour schemes (the converter already understands them).
- Online update repository for the Whistler packages (today they come from `/opt/whistler/repo`
  on the installed system).
